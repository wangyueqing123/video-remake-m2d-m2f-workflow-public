# R6.20 原声时间轴锁定的大场景视觉二创合同

## 模式定义

`M2_F_SOURCE_AUDIO_RESTYLE` 使用原 MP3 和逐字文案，但不只靠文案猜画面。四种权威严格分开：

| 权威 | 决定什么 |
|---|---|
| 原 MP3 | 总时长、句子和动作节点的目标时间 |
| 逐字文案 | 说了什么、顺序和字幕文字 |
| 源视频 | 大场景、动作主体、动作对象、动作路径、因果顺序、可见结果 |
| 目标风格与视觉锚点 | 新人物、新动物、新环境、新构图和跨段一致性 |

源视频像素、构图、镜头、切点和关键帧没有生图权威，不得成为 ImageGen 参考图。因此本模式继承“视频表达了什么”，不复刻“原画面长什么样”。

## P2：源大场景证据

建立 `artifacts/P2/SOURCE_MACRO_SCENE_EVIDENCE.json`：

- 全片至少每秒观察一次，并检查动作/事件边界；
- 每个源大场景记录主体、对象、路径、因果和可见结果；
- 明确禁止的错误替代，例如把“手先移开盘子”改成“人与狗赛跑”；
- 对源像素、构图、镜头、切点、关键帧和生成参考图显式拒绝权威；
- 关键动作不确定即阻断，不用文案常识补写。

## P3：原声—文案—源场景对齐

`SOURCE_AUDIO_PLAN.json` 必须：

- 无缝覆盖完整原 MP3 和完整逐字文案；
- 每段绑定一个或多个按顺序排列的 `source_scene_ids`；
- 从 P2 原样继承 `inherited_action_contracts`；
- 原声固定 1.0 倍速，不裁切、不换声、不改字、不调序；
- 视觉义务可以换外观和镜头表现，但不能替换核心动作。

## P4-P6：共同视觉核心

P4 再次原样继承 P3 动作合同，按完整大场景建立一段一宫格。P5 必须把动作主体、对象、路径、因果、结果及禁止替代编译进 Prompt。P6 继续执行空间可达性、接触、状态、拓扑、视觉锚点和上一段末态审核。

G01 建立项目视觉锚点；G02+ 使用项目锚点与上一段末格。源视频关键帧和源宫格不得进入 ImageGen 输入。

当前内置 ImageGen 测试路径固定使用 `imagegen_capability_profile_id=CODEX_BUILT_IN_IMAGEGEN_PROMPT_ONLY`、`FLEXIBLE_REFERENCE` 与 Prompt 9:16 构图指导；比例不精确不得在 P5 阻断，而应在 P6 实测并进入确定性裁切。改用暴露尺寸参数且已验证的图像 API 时，必须新建项目修订并切换为 `PROJECT_VERIFIED_EXACT_GEOMETRY`。

## 与其它路线的边界

- M2-A：源像素、镜头、切点、空间和动作路径全部保留，只换批准外观。
- M2-D：允许转发优先改写、新旁白和新叙事蓝图。
- M2-F：原声原文不变，源视频只锁大场景动作语义，画面全面重构。

旧 R6.17-R6.19 M2-F 的 P3-P9 物料建立在“只按文案反推”的错误权威上，不能换标签复用；保留为审计证据并从 P2 重新建立。

## 最终装配

草稿只放一条完整原 MP3，速度 `1.0`；模型视频全部静音。视频裁剪或轻调速服从原声节点；字幕逐字来自锁定文案，时间来自原声对齐。
