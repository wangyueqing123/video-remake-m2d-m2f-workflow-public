# R6.7 Prompt 编译合同

## 机器合同与模型 Prompt 分离

JSON、哈希、枚举、路径、预算和审批证明用于机器校验；供应商 Prompt 使用直接、可视化的自然语言。不得把状态机语法或审计说明粘进 Prompt。

## 动作宫格 Prompt 顺序

1. 当前 `segment_id`、一张完整宫格、布局、画布/单格比例、行优先时间顺序；
2. 当前路线的结构权威；
3. 单一批准风格；
4. 人物、动物、环境、道具和配色锁；
5. **当前段**的内容义务；
6. 当前段场景的大动作方向；
7. 当前段逐格静态时刻和状态锁；
8. 连续性与物理拓扑；
9. 无文字、无重复、无穿模、无提前结果等禁止项。

编译器只能读取所选宫格绑定的段。整片主题可提供语境，但其它段的动作、结果和口播义务不得进入当前宫格 Prompt。

## 每格语言

每格只描述一个冻结时刻：当前可见主体、动作阶段、空间关系、状态账本和是否为结果格。场景大动作可在逐格描述前说明一次，但不能提前写出最终状态。

结果文本只进入 `result_visible=true` 的格子。非结果格明确禁止出现未来结果。

M2-F 在逐格描述前增加一份简短的“源视频大场景语义锁”：动作主体、对象、路径、因果、结果和禁止替代表达。它来自 P2/P3/P4 的哈希血缘，不从当前聊天补写；不得包含源像素、镜头或关键帧复刻要求。

## 长度预算

逐格状态锁不能截断。当前编译上限：

| 布局 | 最大字符数 |
|---|---:|
| 2×2 | 4,000 |
| 3×3 | 6,500 |
| 4×4 | 9,000 |
| 5×5 | 13,000 |

超限时先删除全局重复，不得删除关键状态、拓扑、禁止替代或最终结果。上限是本地编译预算，不代表供应商官方上限；P8 仍需根据当前接口检查。

## 参考图角色

- `STRUCTURE_REFERENCE`：仅 M1/M2-A 可控制构图、裁切、空间结构和动作相位；
- `IDENTITY_STYLE_REFERENCE`：只控制批准的人物、服装、配色、线条或环境风格；
- `CONTENT_EVIDENCE`：用于确认事实和主题，默认不作为结构图。
- `PROJECT_VISUAL_ANCHOR`：控制跨宫格人物、动物、画风和核心环境，不控制当前段动作顺序；R6.6 要求项目相对路径和 SHA256。
- `PREVIOUS_SEGMENT_END_STATE`：只控制连续边界的下一段入口状态，来自上一张通过 QC 宫格的末格确定性裁切。

如果工具不能硬绑定角色，审核包必须承认限制，不能把数组顺序说成官方硬槽位。

自然语言“与上一段相同”只有在模型调用实际携带对应参考图时才有效。Prompt 编译审计必须声明 `visual_anchor_required`、`project_anchor_role_expected` 和 `previous_end_state_role_expected`；机器合同负责验证图片，Prompt 不嵌入文件哈希。

## 视频 Prompt

每个 `video_segment` 单独生成一个 Prompt，内容包括：段时长、当前宫格、普通单画面输出、起始状态、主体路径、唯一交互通道、决定性动作、可见结果、镜头、连续性、后期旁白义务和禁止替代。

不按格子均分时间。段时长由完整动作和完整句子决定。

- 默认 `POST_DUB_NARRATION`：Prompt 明确“无对白、无需口型、音频后期替换”，旁白句子只用于动作时长规划和后期脚本；不得要求视频模型朗读。
- 主角口播暂时禁用；只有未来建立独立模式、能力证据和人工批准后才能启用。

## 禁止行为

- 把风格扩展成内容权限；
- 创意路线使用源宫格空间结构；
- 一张全片宫格服务多个视频段；
- 当前段 Prompt 包含后续段结果；
- 为填满宫格编造动作；
- 把每格写成前态、动作和后态叠加；
- 为省字符删除状态账本或结果；
- 在 Prompt 中嵌入哈希/调用控制；
- 声称未验证的比例、时间码或首帧能力。
