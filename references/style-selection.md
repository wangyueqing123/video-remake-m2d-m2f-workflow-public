# 画风选择合同

画风是独立轴，不是内容路线。

## 默认

未指定时选择 `DOG_HIGH_SHARE_MONO_COMIC`：黑、白、中性灰为基础色，只允许P1登记的局部强调色；黑色粗轮廓、简洁灰阶色块，狗是第一主体，主人只辅助叙事。

## 可选预设

- `DOG_STYLE_C_GHIBLI_PET_NARRATIVE`：温暖日式手绘二维生活叙事，不复刻任何具体影视画面。
- `DOG_STYLE_D_INDOOR_CARE_KEYFRAME`：日式二维轻写实室内宠物照护，强调工具、接触面、动作路径和结果。
- `DOG_STYLE_E_REACTION_RESONANCE`：日式二维轻拟人反应共鸣，保持犬类身体结构和清晰因果。
- `CUSTOM_NAMED_STYLE`：必须登记完整的视觉词汇、色彩、线条、身份、环境、连续性和负面约束。

## 约束

- P1同时锁定 `style_profile`、`identity_profile` 和命名强调色。
- 换风格不自动换人、换狗、换场景或换道具；这些必须分别授权。
- G01依据P1建立视觉锚点；G02+必须同时参考项目锚点和上一段末格。
- 风格改变后必须新建项目修订并重建P3-P9。
- 禁止混合未批准风格、复刻具体版权画面或让风格覆盖动作可读性。
