# M2-F 原声换画面合同

`M2_F_SOURCE_AUDIO_RESTYLE` 的目标是只换画面，不改变原声内容。

## 四种权威

1. 原MP3：唯一声音与时间权威，完整使用、1.0倍、不裁切。
2. 逐字文案：唯一字幕与内容权威，不改写、不增删、不重排、不翻译。
3. 源视频：只提供完整大场景动作、因果和结果语义。
4. P1风格合同：控制新画面的风格、身份、环境和镜头语言。

源关键帧、源宫格、源构图、源镜头切点都不是ImageGen输入权威。

## 规划

- P2按原声句子与源动作证据建立大场景映射。
- P3锁定原MP3哈希、逐字稿和句级时间。
- P4按完整大动作场景分段，不能只按文案常识猜画面。
- P7视频长度服从原声覆盖范围；P9只调整视频，不改原声。

## 输出

- Grok生成音轨全部静音。
- 剪辑草稿只使用原MP3。
- 字幕使用原文，并根据原声ASR词时间对齐。
